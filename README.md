# Valenced plugins

JavaScript-only plugins for Valenced on sideloaded Discord for iOS.

## Install

Add this repository URL in Valenced's plugin repository settings:

```
https://raw.githubusercontent.com/thetoadsage/valenced-plugins/gh-pages/index.json
```

Install **Toad URL Cleaner** or **Message Logger for iOS** from Browse and enable it. Disable the corresponding original community plugin first to prevent overlapping hooks.

Plugin ZIPs are also available as build artifacts. Some iOS builds hide the file installer, so use the repository's Browse screen when available. These are plugin ZIPs, not IPAs; Discord does not need rebuilding.

## Toad URL Cleaner

Ports the cleaning engine from [Clipboard Cleaner](https://github.com/thetoadsage/clipboard-cleaner), using Valenced Clear URLs as the Discord integration reference.

- Removes tracking using the complete bundled catalog, including site/path exceptions and value-based preservation rules.
- Handles Instagram sharing parameters, KKInstagram `mdxt`, and contextual YouTube sharing/radio/favorites cleanup while retaining ordinary playlists and timestamps.
- Locally unwraps supported Facebook, Instagram, Threads, Google, Bing, DuckDuckGo, Reddit email, LinkedIn, and affiliate redirect formats.
- Cleans individual links inside messages while preserving surrounding prose, Markdown delimiters, code spans, and code blocks.
- Preserves untouched query spelling, duplicate values, and fragments during normal tracking removal.
- Has independent copy, send, and edit switches, all enabled by default. Received messages are left unchanged.

**Shorten product and model links** is off by default. Enable it to use Clipboard Cleaner's canonical forms for Amazon, AliExpress, Best Buy, Walmart, and MakerWorld. This discards query options and fragments, including MakerWorld profile selection. Custom ports and credential-bearing URLs are never canonicalized.

Disable the community **Clear URLs** plugin before enabling this one. Copy cleaning applies to Discord's clipboard actions; it does not watch the system clipboard or clean content copied in other apps. No URLs, messages, or cleaning history are stored or sent to a server. Rules are bundled with the plugin, and opaque shorteners such as `t.co` and `bit.ly` are not resolved over the network.

The initial version targets Discord 352.x / Valenced API 1.x on iOS. It has build and integration coverage but has not been tested on a physical iPhone. The message hooks support string and `{ content }` payloads; private Discord APIs may change. Ambiguous text boundaries and unusually formatted Markdown may remain uncleaned. URL tokens above 8 KiB and messages above 65,536 UTF-16 code units pass through unchanged.

Development checks execute the actual packaged JavaScript bundle without browser URL globals. A committed corpus of 472 reference inputs is generated by running the Swift cleaner. To refresh the catalog and corpus from a reviewed local Clipboard Cleaner checkout on macOS (requires Swift):

```sh
python3 scripts/sync-url-cleaner.py /path/to/clipboard-cleaner
npm test
```

Review imported rule changes and bump the plugin version before publishing an update. The engine adds stricter malformed-URL handling and preserves custom ports/credentials when canonical rewriting would change the destination.

## Message Logger for iOS

Adapted from Valenced Community Plugins' mobile Message Logger, with Vencord MessageLogger behavior as a reference. It has no Android JAR, native dylib, jailbreak dependency or remote logging service.

- Retains deleted messages and removed attachments already present in Discord's cache.
- Shows earlier text versions in numbered quote blocks with capture times and a clear current-version label, plus a scrollable, selectable history reader. The reader highlights word additions/removals and displays Discord version timestamps and local capture timestamps when available. Older records without timestamps are labeled accordingly.
- Flags deleted messages that directly mentioned you as **Ghost ping**, in chat and saved history, with a dedicated filter. This does not detect role/everyone mentions or messages deleted while Discord was closed.
- Optionally downloads files from deleted messages and removed attachments. Saved files open through the iOS share sheet, even after their Discord links expire.
- Marks retained messages with a `[Deleted]` label and a critical text color.
- Saves deleted text, attachment metadata, and edit history in separate archives for each Discord account.
- Searches saved text, previous versions, authors, channels, and dates, with deleted/edited/ghost-ping filters. Saved history opens even when Discord no longer has the message cached.
- Removes one saved entry, a channel's history, or all saved history for the current account.
- Includes toggles for deletions, edits, removed attachments and inline history.
- Can ignore bots, your own messages, user IDs, channel/category IDs and server IDs.
- Clears live session state on account changes and restores retained cache entries when disabled. Saved archives remain on disk across logout, disable, and app restarts.

Under **Text colors**, tap **Deleted text color** or **Edited text color** to expand a picker with a preview, RGB sliders, and hex input. Defaults are red (`#ED4245`) and orange (`#FAA61A`). Tap **Apply** to save; **Reset** previews the default until applied, and **Cancel** discards the draft. Colors persist across restarts and update existing logged rows. Discord’s iOS native chat renderer applies one color per message row, so the entire edited row uses the edited color, and deletion takes precedence when a message was both edited and deleted. Previous versions are visually separated as quote blocks; no separate synthetic messages are added. In the history viewer, previous versions and added diff text use the edited color, while the latest deleted version and removed diff text use the deleted color. The current live version retains its normal history-viewer color. Preview chosen colors against your current theme.

Open the plugin's settings for **Saved history**, search, and retention controls. The default limits are **30 days**, **1,000 messages**, and **5 MiB per account archive**, plus a recovery copy of up to the same size. The configurable maxima are **50,000 messages**, **50 MiB of message history**, **25 MiB per downloaded file**, and **100 MiB of saved files** per account. The history recovery copy can use another 50 MiB. Larger message archives increase memory use and save time because message history is loaded and rewritten as one JSON file. Attachments are stored as individual binary files; their index contains metadata only. At most 50 previous versions are kept per message. Edit the limits and tap **Apply retention limits now** to save them; lowering limits permanently removes excess history. Retention is enforced when loading, opening history, saving, or applying limits. Results display 50 at a time with **Show more messages**. Search matches all entered words across content, author names/IDs, channel names/IDs, and saved dates (including `YYYY-MM-DD`).

History files use `Documents/valenced/messagelogger/messages/<account-id>/archive.json` and atomic native writes, with serialized batches and a validated recovery copy. Read/write errors appear in settings and plugin errors; unreadable files are preserved until explicitly cleared. Settings use the standard JSON Storage API. See Valenced's [storage](https://valenced.app/docs/plugin-development/api-reference/storage/), [native filesystem](https://valenced.app/docs/plugin-development/api-reference/native/), and [lifecycle](https://valenced.app/docs/plugin-development/api-reference/lifecycles/) documentation.

 Long-press a logged message for **View message history**, **Toggle Deleted Highlight**, or **Remove History**. Long-press a channel to clear its log.

## Message Logger compatibility and limits

The initial target is Discord **352.0** with Valenced **1.3.0** on iOS. The manifest accepts Discord 352.x. The plugin is experimental: local integration tests and builds do not establish physical-device compatibility. Its private Discord UI hooks still need iPhone testing.

Saved history persists locally as unencrypted JSON in Discord’s Documents folder. With document sharing enabled in the installed IPA, browse **Files → On My iPhone → Discord/Valenced → valenced → messagelogger**:

- `messages/<account-id>/archive.json` and `archive.json.bak` contain message history and its recovery copy.
- `attachments/<account-id>/` contains ordinary attachment files and a metadata-only `index.json`. Filenames include message and attachment IDs to avoid collisions.

This version starts fresh in these folders. Previous plugin-storage archives are not imported or deleted. Files visibility requires `UIFileSharingEnabled` and `LSSupportsOpeningDocumentsInPlace` in the installed IPA; a JavaScript plugin cannot enable those app settings. Moving or deleting attachment files makes them unavailable to the logger; **Retry attachment downloads** can restore missing files while their Discord links remain valid. Retention and clear actions delete the corresponding files. Move copies outside this folder to keep them independently. Editing the JSON manually may make the archive or attachment index unreadable.

Saved history remains in Discord’s app sandbox. It has no iCloud sync or export feature. Removing the plugin or Discord can remove its storage. Writes begin on logged changes, with an additional flush on backgrounding/stop; abruptly terminating the app before a write finishes can lose the newest changes. Restarted history remains available in settings. When **Show earlier versions in chat** is enabled, saved edit history appears inline on matching loaded messages, including restored deletions. Enable **Show saved deletions in chat** under Display to restore saved text into the channel history you have loaded. This setting is **off by default**. Restored rows always carry a `[Saved deletion]` label. Exact message IDs determine order without floating-point rounding; existing server messages take precedence and repeated loads do not duplicate restored rows. Pagination respects the loaded range and known channel edges. Native startup-cache matches can be labeled from the archive; a fresh server batch can supersede that label.

Restoration uses Discord’s native message factory and channel collection, leaving shared message-load events unchanged for other stores. It does not dispatch synthetic message-create events or re-send messages. Turning the option off removes restored rows while retaining the archive. Restored rows show text and saved inline edits; rich embeds, replies, and reactions are not reconstructed from incomplete snapshots. Long-press **View message history** to read earlier versions and access attachments. Restoration uses private Discord hooks; native behavior should be checked after Discord or plugin updates. It cannot recover messages deleted before the plugin received them, or fetch messages your account cannot access. Attachment names, IDs, and links are always retained with logged messages; links can expire or stop working. Enable **Download deleted attachments** to save file bytes locally as well. Downloads are **off by default**, use your network connection, and are limited to Discord attachment CDN URLs. Defaults are **5 MiB per downloaded file** and **25 MiB per account for saved files**, separate from the text archive. The file cache limit counts binary file bytes and index metadata, without base64 storage overhead. Configure limits in settings and tap **Apply retention limits now**. Files follow message retention and oldest files are removed when the file cache fills. Disabling downloads preserves existing saved files. **Clear saved attachment files** removes files without clearing text; **Retry attachment downloads** retries failed/cleared files with still-valid links. Clearing all saved history removes its saved files too. Interrupted or expired downloads may fail; status appears beside each attachment. The attachment index uses atomic writes and has no extra recovery copy. Interrupted binary-file writes can leave an incomplete or unindexed file; clearing saved attachment files resets the account’s attachment folder. Long edit comparisons above 400 word/whitespace tokens per version use whole-version removal/addition to bound processing time. The recovery copy is local and does not protect against app deletion or loss of the device. Attachments and avatars are not dimmed by Android-native hooks. Desktop CSS overlays and desktop collapsed-message styling are not included.

## Build

Use Node 26 and npm:

```
npm ci
npm run lint:types
npm run lint
npm test
npm run package
```

ZIPs are written to `build/dist`. The public `gh-pages` branch holds versioned packages and a generated, SHA-256-verified `index.json`. Publishing refuses to replace an existing version with different bytes.
